## §1 环境纪律（铁律，逐条生效，违反即事故）

1. **只读先行**：当前阶段一切动作只读——勘察、枚举、读版本、读日志、读配置。**零 WQE 发射、零内存写入对端、零配置修改**。发射授权由任务书逐 DO 单独给出，本文档不构成任何发射授权。
2. **device 白名单现场定**：开发机的"device 1↔2"纪律**不照搬**。本机哪些 device 可用、哪个是 TGT 侧，以现场勘察（npu-smi）+任务书指定为准；未列入白名单的 device 一律不碰。
3. **严禁动真 TGT**：不修改真 TGT 的任何配置、进程、启动参数、固件态。只允许只读观察与既有公开接口交互。
4. **不重启**：任何情况下不重启机器、不复位 device、不重启任何服务（含 hccp_service）。没有例外。
5. **撞码即停手**：任何 CQE 非零 status、任何调用返回非常态错误码——**停手、保留现场（日志/现场文件不清理不覆盖）、如实登记码值与上下文**，不自行重试超过一次、不猜因修复。
6. **取证纪律**：一切结论带证据（日志原文、时间戳、命令原文、文件 md5）。凭记忆的描述不写入 REPORT。
7. **封存件只读**：包内标"封存/禁改"的文件只拷贝不修改；每次任务收尾自证封存件 md5 不变。
8. **代码修改记录**：任何代码改动逐条记录（文件:行区+改动内容+理由），写入 REPORT——这是硬要求，用于跨环境文本同步。

## §2 最小技术背景（看懂任务书所需）

### 2.1 三通道形态（全部单边 RDMA 语义，无需对端预投递）

| 通道 | 方向 | 语义 | 落点 |
|---|---|---|---|
| 命令面 | INI→TGT | WRITE_WITH_NOTIFY（opcode=5，双块 WQE 128B） | 对端收件箱槽位+notify 置 valid |
| 数据面 | TGT→INI | RDMA WRITE | INI 侧 HBM 数据目标区 |
| 回执面 | TGT→INI | RDMA WRITE | INI 侧 HBM 回执区（AIV 图内收割） |

### 2.2 关键事实（本机已实证，作为你的先验）

- WQE 双块 128B：WQEBB0=ctl 48B+NotifyCtx 前 16B；WQEBB1=NotifyCtx 后 16B+SGE；notify 语义=硬件向 notifyAddr 写 notifyData（u64，恒 1=valid 置位）；
- SQ 环槽位 64B（SQEBB），门铃 head 以块为单位，WRITE_WITH_NOTIFY 每条步进 2；
- 发射纪律：slot0 写→无害门铃（magic=0 不推进）→slot1 写→真门铃（head+2）——保双块原子性；
- CQ 收割：owner-bit 相位轮询；回执收割：AIV 轮询 valid→比对→清位复用；
- dbuf 布局（HBM，注册进 channel 共享域）：cqe_va@+0x100（32B）／data_va@+0x200（256B）／fire_idx@+0x500／prep 包@+0x600（200B）／inbox@对端 +0x800（8 槽×128B）。布局常量唯一出处=包内 include/ 布局头。

### 2.4 项目边界口径（Govern 裁定）

真 TGT 能力边界既定（标准 NoF 惯例：回执写 host DRAM、命令收 SEND 带内、不写对端 HBM），不为本项目改变；**缺口全部由我方适配层填补**。真 TGT 对接=我方适配层与真 TGT 惯例的缝合，缝合点两处：①inbox 地址获取段；②回执落点段。勘察的目标之一就是把这两处的真 TGT 侧事实摸清。
